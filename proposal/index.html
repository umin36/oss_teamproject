    ttak-pul

    1. 프로젝트 주제

    같은 화면을 아래로 스크롤하며 찍은 여러 장의 스크린샷을 긴 이미지 한 장으로 합치는 오픈소스 Python 라이브러리를 개발한다. 이미지 사이에 겹치는 본문을 찾아 한 번만 남기고, 반복되는 상·하단 메뉴를 정리한다.

    사용자와 해결할 문제

    강의 공지, 웹페이지, 채팅 기록 등을 여러 장으로 캡처해 공유하는 사용자를 대상으로 한다. 사진을 그대로 보내면 읽는 사람이 여러 장을 오가며 같은 내용을 다시 읽어야 하고, 한 장으로 합치려면 사용자가 각 사진을 직접 잘라 위치를 맞춰야 한다. 이 작업을 자동화하고, 연결 위치가 애매할 때는 확인이 필요한 이미지 쌍을 알려준다.

    2. 계획 기능

    입력

    같은 기기와 화면 배율에서 하나의 화면을 세로로 스크롤하며 촬영한 PNG 스크린샷 2장 이상을 받는다. 이미지는 모두 너비가 같아야 하며, 위에서 아래로 찍은 순서대로 입력한다. 인접한 두 이미지에는 공통 본문이 있어야 한다.

    처리 과정

    1. 입력 검증 — 이미지가 정상적으로 열리는지, 2장 이상인지, 모든 이미지의 너비가 같은지 확인한다. 조건을 충족하지 않으면 해당 파일과 이유를 알려준다.
    2. 고정 영역 탐지 — 여러 이미지의 같은 화면 위치에 나타나는 상단 메뉴와 하단 버튼을 비교해 본문 범위를 추정한다. 검출한 고정 영역은 본문 비교에서 제외한다.
    3. 겹침 위치 탐색 — 인접한 두 이미지에서 앞 이미지 본문의 하단과 뒤 이미지 본문의 상단을 비교한다. 글자나 경계가 나타나는 구간의 픽셀 유사도를 계산해 겹치는 높이의 후보를 찾는다.
    4. 연결 위치 판단 — 유사도가 낮거나 여러 후보의 점수가 비슷하면 확인이 필요한 이미지 쌍을 표시한다. 확인이 필요한 구간의 연결 위치는 사용자가 지정할 수 있도록 한다.
    5. 이미지 합성 — 확정된 겹침 구간을 한 번만 남기고 본문을 순서대로 합친다. 고정 메뉴가 검출되면 첫 이미지의 상단 메뉴와 마지막 이미지의 하단 메뉴를 각각 한 번씩 남긴다.

    출력

    연결에 성공하면 원본 너비와 색을 유지한 긴 PNG 이미지를 제공한다. 연결 위치를 확정하기 어려우면 이미지 쌍의 번호와 가능한 겹침 높이 또는 실패 이유를 반환한다. 샘플 앱에서는 합성 결과를 미리 보고 PNG를 저장할 수 있다.

    지원 범위와 한계

    • 기본 지원 범위는 같은 화면에서 순서대로 찍은 세로 스크롤 PNG다. 서로 다른 화면 배율, 가로 스크롤, 촬영 순서 자동 추정은 초기 범위에서 제외한다.
    • 화면이 갱신되거나, 비슷한 내용과 빈 여백이 반복되거나, 겹치는 본문이 너무 적으면 자동 연결이 어려울 수 있다. 두 캡처 사이에 실제로 촬영되지 않은 내용은 복원할 수 없다.

    사용 예시

    학생이 강의 공지 페이지를 아래로 스크롤하며 찍은 notice-01.png부터 notice-04.png까지의 파일을 순서대로 불러온다. 샘플 앱은 설치된 라이브러리를 호출해 공통 본문을 찾고, 공지 제목과 항목이 원래 순서대로 한 번씩 나타나는 notice-merged.png를 생성한다. 상단 메뉴는 결과 맨 위에 한 번만 표시된다.

    3. 구현 및 검증 계획

    이미지 처리 함수는 Python 라이브러리 저장소에 구현한다. 별도 저장소의 샘플 앱은 라이브러리를 설치하고 가져와 입력 선택, 결과 미리보기, PNG 저장을 제공한다.

    담당 구현할 기능 함수 이름 예시
    1 파일 읽기와 입력 조건 검사 validate_images()
    2 고정 영역 탐지와 본문 범위 추정 detect_fixed_regions()
    3 인접 이미지의 겹침 높이 후보 탐색 find_overlap_candidates()
    4 후보 신뢰도 판단과 애매한 연결 표시 assess_overlap()
    5 연결 위치를 반영한 이미지 합성과 출력 stitch_images()

    긴 원본 이미지를 시작 위치가 알려진 여러 조각으로 잘라, 추정한 겹침 높이와 실제 높이의 차이를 확인한다. 실제 강의 공지 캡처로는 글줄의 중복·누락과 고정 메뉴의 반복 여부를 확인한다. 겹침이 없는 이미지와 유사한 내용이 반복되는 이미지에서는 잘못 연결하는 대신 확인이 필요한 구간을 표시하는지 검사한다.
