# Team rules

## Commit
- 커밋 메세지: 변경사항을 간단하게 기록
## Pull request
- PR 등록하면 단톡방에 등록 사실 알리기
- 브랜치 이름: `<user_name>/{feat/fix/docs/chore}/<name>`
- size: 100줄 상한, 최대 한 개의 함수/클래스 추가만 허용. 
- issue: 한 번의 PR이 이슈를 완전히 해결하지 않더라도 어떤 이슈를 해결하기 위한 것인지 반드시 표기. issue를 close하는 PR이라면 README, docstring을 업데이트 하기.
## Review
- PR 마다 72시간 내에 최소 2인 이상 리뷰하고 승인
- 단톡방에 PR 등록 사실이 알려지면 24시간 내에 리뷰할 사람이 체크 표시 남기기
- 리뷰어는 참여하고 싶은 PR에 자율적으로 참여. 다만 아무도 지원자가 없다면 리뷰 횟수가 가장 적은 사람이 우선적으로 참여해야 함.

리뷰 체크리스트
- 모든 요구 사항을 충족했는가?
- 생각 못한 부분이 있나?
-  테스트가 정확한가?
## Merge
- 마지막(두 번째) 리뷰어가 merge 하기
- 반드시 `--no-ff` 설정으로 새 커밋 생성, merge 후에는 브랜치 삭제할 것.
## AI use
AI를 사용한 경우 PR 템플릿의 AI use 항목에 전부 기록.
모든 PR에서 `## AI use` 항목을 채울 것.
